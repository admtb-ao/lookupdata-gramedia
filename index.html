Automasi Lookup Data Gramedia

Cari data manual (Buku & Toko) atau upload Excel massal. Web ini dilengkapi Auto-Scan Header dan pencarian fleksibel dari Multi-Database.

Status Database: Sedang Menghubungkan ke 2 Google Sheet... ⏳

Ketik ID ORIN, Kode Bsoft, atau Judul Buku (contoh: garda / leika) lalu tekan Enter. (Kosongkan lalu tekan Cari untuk memuat semua data).

Ketik bagian dari nama toko (contoh: gajah mada atau surabaya). Klik Detail pada hasil pencarian untuk melihat stok seluruh buku di cabang tersebut.

Upload file Excel Anda (mengandung kolom Item Id/ID ORIN/KODE BSOFT/iditem). Sistem otomatis memindai dan mensinkronisasi datanya ke seluruh toko nasional.

Centang data apa saja yang ingin disisipkan ke dalam file Excel Anda.
